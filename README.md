# Custom Nodes for n8n

This repository contains custom nodes for [n8n](https://n8n.io/), the extendable workflow automation tool.

## Getting Started

1. Clone this repository:
    ```bash
    git clone https://github.com/your-username/custom_nodes.git
    ```
2. Copy the custom nodes to your n8n installation's `nodes` directory.
3. Restart n8n to load the new nodes.

## Folder Structure

```
custom_nodes/
├── node1/
├── node2/
└── ...
```
